# A two-minute portfolio demonstration

1. **Introduce the problem (15 seconds).** “Salescope helps turn spreadsheet sales records into understandable trends and forecasts.”
2. **Explore the dashboard (25 seconds).** Show the revenue chart, change the store filter, and explain that KPIs and charts use the same selected records.
3. **Explain data validation (20 seconds).** Show Data workspace and the required date/revenue mapping. Mention explicit missing-day treatment and preserved returns.
4. **Generate a forecast (25 seconds).** Open Forecast studio, choose 30 days, and run it. Explain that it compares a seasonal baseline with two machine-learning models.
5. **Show evaluation (20 seconds).** Open Model performance. Explain chronological validation and the final untouched period. Point out that accuracy claims are based on measured errors, not a fabricated percentage.
6. **Export (15 seconds).** Open Reports & guide and download the Excel report.

Always identify the demonstration data as synthetic. The app forecasts after the dataset's last date, so do not describe its January 2026 demo forecast as a current-day prediction.
